
# Comandos básicos de Linux

## 1. Mostrar el directorio actual

```bash
pwd
```

Muestra la ruta de la carpeta actual.

## 2. Listar archivos

```bash
ls -la
```

Muestra archivos y carpetas, incluidos los ocultos.

## 3. Identificar el usuario

```bash
whoami
```

Muestra el nombre del usuario actual.

## 4. Consultar la fecha y hora

```bash
date
```

Muestra la fecha y hora del sistema.
