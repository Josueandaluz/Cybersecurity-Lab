# Cybersecurity-Lab
Laboratorio personal de aprendizaje de ciberseguridad

## Sobre este proyecto

Este repositorio recoge mi aprendizaje práctico de ciberseguridad desde cero.

## Objetivos

- Aprender fundamentos de ciberseguridad.
- Practicar comandos básicos de Linux.
- Comprender redes y protocolos.
- Aprender a analizar registros de sistemas.
- Documentar prácticas de seguridad defensiva.

## Contenido

- Fundamentos de ciberseguridad
- Linux y terminal
- Redes y protocolos
- Análisis de registros
- Laboratorios autorizados

## Entorno

- GitHub desde el navegador
- Kali Linux para futuras prácticas
- Herramientas gratuitas

## Aviso

Todas las prácticas se realizarán en sistemas propios
o en laboratorios donde tenga autorización.
